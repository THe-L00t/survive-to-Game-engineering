# 🦖 C++ & OpenGL: Chrome Dino Run 모작

이 프로젝트는 크롬 브라우저의 오프라인 게임인 **Dino Run**을 C++와 OpenGL(GLFW/Glad) 환경에서 구현한 모작 프로젝트입니다.

---

## 🛠 기술 스택 (Tech Stack)

* **Language:** C++26
* **Graphics Library:** OpenGL 3.3+ (Core Profile)
* **Windowing & Context:** GLFW3
* **OpenGL Loader:** GLAD
* **Math Library:** GLM (OpenGL Mathematics)

---

## 🏗 프로젝트 구조 (Project Structure)

### 1. Game Loop & Core
* **`main.cpp`**: GLFW 창 설정, 입력 처리 및 메인 게임 루프 관리.
* **`Shader` class**: GLSL 셰이더 소스 컴파일 및 프로그램 링크 관리.
* **`Renderer` class**: VAO/VBO 설정 및 텍스처 바인딩, 그리기 호출(Draw Call) 추상화.

### 2. Game Objects
* **`Dino`**: 플레이어 조작, 물리 법칙, 애니메이션 상태(Run/Jump/Duck) 관리.
* **`Cactus`**: 장애물 클래스. 화면 왼쪽으로 이동하며 화면 밖으로 나가면 재사용(Object Pooling).
* **`Background`**: 무한 스크롤되는 바닥(Ground) 및 구름(Cloud) 레이어.

---

## 🚀 핵심 구현 로직

### 1. 좌표계 (Coordinate System)
2D 게임 구현을 위해 **Orthographic Projection(정사영 투영)**을 사용하여 화면을 픽셀 단위(예: 800x600)로 제어합니다.

$$P_{clip} = M_{ortho} \cdot M_{model} \cdot V_{local}$$

### 2. 물리 및 점프 (Physics)
* **상태 업데이트**:
    * $v_y = v_y - g \cdot dt$ (속도에 중력 적용)
    * $y = y + v_y \cdot dt$ (위치 업데이트)
* **바닥 충돌**: $y \le y_{ground}$ 이면 $y = y_{ground}$ 및 $v_y = 0$으로 초기화.

### 3. 충돌 감지 (AABB Collision)
오브젝트의 경계 상자가 겹치는지 확인하는 **AABB(Axis-Aligned Bounding Box)** 알고리즘을 사용합니다.

```cpp
bool AABBCollision(GameObject &one, GameObject &two) {
    // x축 겹침 확인
    bool collisionX = one.Position.x + one.Size.x >= two.Position.x &&
                      two.Position.x + two.Size.x >= one.Position.x;
    // y축 겹침 확인
    bool collisionY = one.Position.y + one.Size.y >= two.Position.y &&
                      two.Position.y + two.Size.y >= one.Position.y;
    
    return collisionX && collisionY;
}
